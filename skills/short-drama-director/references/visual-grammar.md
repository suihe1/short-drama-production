# 视听语言与镜头语法

## 1. 景别不是尺寸标签

按叙事功能选择景别：

| 景别 | 主要功能 | 常见误用 |
|---|---|---|
| EWS/大全景 | 建立世界、尺度、孤立或危险 | 人物太小却承担细微表演 |
| WS/全景 | 展示全身动作、人物与空间关系 | 对话全程不变化，缺少重点 |
| MWS/中全景 | 同时保留身体策略与表情 | 仅作为“过渡景别” |
| MS/中景 | 对话、手势、关系调度 | 每句台词都切同样中景 |
| MCU/中近景 | 表演和关系压力 | 全片滥用导致无层级 |
| CU/近景 | 决定、发现、隐藏的反应 | 把普通信息拍成虚假高潮 |
| ECU/大特写 | 不可忽视的微表情或证据 | 缺少建立导致观众不知所见 |
| INSERT/插入 | 道具状态、文字、关键细节 | 重复画面已清楚的信息 |
| OTS/过肩 | 保留对手压力和空间关系 | 肩部遮挡脸或方向错乱 |
| TWO_SHOT/双人 | 同盟、疏离、权力同框变化 | 两人并排说话，没有关系设计 |
| POV/主观 | 限制信息、强化身份体验 | 与客观镜头无区分 |

使用景别升级：建立常态后，只有信息或权力升级才靠近。高潮后的退远也可表达代价、隔离或结果。

### 屏幕与载体信息的覆盖

当手机、电脑、票据、文件或道具上的内容推动剧情时，镜头必须区分三件事：人物正在看、载体上的内容、人物看完后的变化。根据阅读负担选择：

- `contextual`：内容不重要，只需知道人物在使用载体。
- `INSERT`：关键图像或极少量信息，载体至少占画面约一半。
- `full-frame-content`：把人物主观看到的视频/照片直接切成全屏内容，再切回反应；它是剪辑视点，不是场景里出现大屏幕。
- `post-composite`：聊天、金额、车次等精确文字或复杂界面，使用可跟踪屏幕并在后期合成。

剧情关键信息不得只留在环境内的小屏幕中。信息镜头之后应判断是否需要反应镜头；已有反应变化时，不重复堆两个只改变裁切大小的眼睛特写。

## 2. 角度与机位高度

- `eye`：平视，适合观察、平衡和不预判。
- `high`：俯视，强调受制、暴露或空间结构；不要自动等同弱小。
- `low`：仰视，强调支配、压迫或决心；不要自动等同英雄。
- `overhead`：顶视，适合图案、困局、行动路径或疏离。
- `dutch`：倾斜，表示秩序失衡；只在剧情已有失衡时使用。
- `ground`：贴地，强化脚步、物体或逼近感。

角度变化必须能说明观看关系发生了什么。连续对话中无动机地一会儿俯一会儿仰会破坏空间和表演。

## 3. 焦段与距离

以下是全画幅等效的叙事倾向，不是硬性规定：

- 18–24mm：扩大空间与速度，近距离会夸张脸和动作。
- 28–35mm：兼顾人物与环境，适合近身调度和竖屏纵深。
- 40–50mm：自然、克制，适合表演与平衡关系。
- 65–85mm：压缩空间、隔离人物、突出微表情。
- 100mm 以上：窥视、远距离压缩或细节，不适合缺少空间建立的全程对话。

“近景”不等于“长焦”。同样的脸部尺寸，广角贴近会让观众进入人物空间，长焦远拍则更像观察。镜头包记录 `lensMm` 时，还要通过 `composition` 和 `blocking` 说明摄影机与人物关系。

## 4. 镜头运动

允许的基础运动：`static`、`pan`、`tilt`、`push`、`pull`、`truck`、`pedestal`、`track`、`arc`、`handheld`、`crane`、`whip_pan`、`roll`。

运动镜头写成完整句法：

`初始构图 + 触发 + 路径/幅度/速度 + 终止构图 + 戏剧结果`

示例：

`双人中景静止；女主把证据推入桌面中央时，摄影机缓慢推进半米并轻微向右修正，最终停在她的中近景与证据同框，让发言权从男主转移到女主。`

判定原则：

- 摄影机追随人物，是为了维持视点或揭示新空间。
- 摄影机主动靠近，是因为认知、危险或决定升级。
- 摄影机拉远，是为了展示代价、隔离或更大的局势。
- 环绕/弧移只在关系中心、阵营或不稳定感发生变化时使用。
- 手持表达身体参与、压力或不可控，不能作为廉价“真实感”。
- 摇焦 `rack_focus` 是焦点变化，不是机身运动；记录在 `focus`。

移动镜头必须填写 `trigger`、`path`、`endState`。`static` 镜头也应有清晰的画面内运动。

### 4.1 画面内运动不是运镜的附属品

逐镜分别设计四层运动：

- 主体运动：眼神聚焦、呼吸、重心、手臂、步态和动作相位。
- 道具运动：手机滑动、布料受力、锅内沸腾、轮子越缝等可见因果。
- 环境运动：蒸汽、雪、车流、屏幕光、背景人流；必须符合真实速度和方向。
- 摄影机运动：只在信息或关系变化时主动移动。

运动写成 `setup → trigger → development → settle`。一镜只设一个主运动，可有一到两个低强度次运动；避免人物、道具、环境和摄影机同时抢夺注意力。`motionPlan.primaryMotion` 记录主运动，`secondaryMotion` 记录次运动，`phases` 写四个相位，`motionLoad` 使用 `low`、`medium`、`high`。提示词必须把这些运动放进对应时间窗，不能只写 `dynamic`、`subtle movement` 或 `cinematic motion`。

判断“运动更好”时分别验收：动作是否启动、是否沿合理路径发展、是否到达可剪的落点、摄影机是否跟上而非替代动作。只看镜头有没有移动会误判。

## 5. 轴线、视线与屏幕方向

建立人物关系轴或运动轴后，同一段连续空间默认保持在轴线同侧。合法越轴方式包括：

- 镜头连续移动越过轴线，让观众看见方向变化。
- 使用轴上中性镜头重置左右关系。
- 人物移动重建新轴，并用全景或双人镜头交代。
- 故意跳轴制造失衡，但必须记录 `axisJustification`，并承担短暂混乱的效果。

视线匹配应核对方向与高度。看向画外左上方的人，下一镜目标不应无理由出现在相反关系。角色从画面右侧出画，连续动作下一镜通常从左侧或符合空间地图的位置入画。

## 6. 构图与层次

构图字段至少说清：主体位置、前中后景、负空间用途、关键道具、遮挡关系。避免只写“电影感构图”。

常用关系表达：

- 同框但被门框/柱子分割：关系破裂或制度阻隔。
- 一人清晰、一人前景虚焦：谁掌握当前信息。
- 人物被留在边缘且面前有负空间：等待、威胁来源或心理缺口。
- 镜面/反射：身份分裂、旁观或被监视；需避免不可能反射和生成穿帮。
- 深焦多层：同时呈现行动者、反应者和后果。

## 7. 切镜与转场

默认使用直接切 `cut`。其他转场必须有具体理由：

- `match_cut`：形状、动作、视线或意义匹配。
- `cut_on_action`：动作中切换，隐藏接点并维持动能。
- `reaction_cut`：结果先落在观察者身上。
- `J_cut` / `L_cut`：声音提前或延续，连接信息和情绪。
- `dissolve`：时间、记忆或状态叠化；短剧中过量会拖慢。
- `whip`：动作方向或冲击匹配；必须可执行。
- `fade`：明确段落边界或终止感。

一个切点至少改变一项：信息、情绪、视点、空间、时间或节奏。连续镜头若没有变化，应考虑合并。

## 8. 可控的风格统一

在 `visualBible` 中固定：

- `cameraPersonality`：观察型、贴身型、克制型、躁动型等，并说明何时例外。
- `lensStrategy`：主焦段、转折焦段、禁用习惯。
- `compositionStrategy`：关系如何占据画面。
- `movementRules`：什么触发移动，什么情况保持静止。
- `continuityRules`：轴线、屏幕方向、色温和道具状态。
- `motifs`：重复的构图、道具或运动，以及每次重复的意义变化。

风格不是每个镜头都相同，而是相同的叙事条件触发相同的视觉规则。
