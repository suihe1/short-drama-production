# 道具设定 · 怎么填

给你原文/大纲里与道具相关的全部信息，先**选**再**填**。**只输出 JSON，不要解释、不要围栏。**结构见 `schema.md` 的 props 段。

## 先选：什么配当叙事道具

三个条件**同时满足**才入选：**有特写、跨集出现、承载剧情**。一部剧通常 3–8 件，跟主角数量一个量级。

| 类型 | 归属 | 例子 |
| --- | --- | --- |
| **叙事道具** | 入选，单独建资产 | 皮箱（全剧悬念）、旧砚（爆点实体） |
| 场景陈设 | 场景锚点已覆盖，不入选 | 铜铃、纸灯笼、系缆石桩 |
| 一次性手部道具 | 镜头级提示词解决，不入选 | 一碗茶、一份报纸 |

拿不准就问一句：这件东西被镜头怼着拍过吗？观众记得住它吗？剧情少了它转不动吗？三个都不是就不入选。

## 硬规则

1. **`summary` 写戏剧功能，不写商品描述。**「谁碰翻谁的脸的悬念核心」是戏剧功能；「棕色牛皮材质」只是材质。先说它在剧里干什么。

2. **锚点要经得起特写。**道具的锚点比场景的更小更细：绿锈铜扣上的一道新划痕、墨池边的月牙磨痕。特写镜头会把这些放大到全屏，**缺了立刻穿帮，多了核对不过来**——照旧 3–5 个。

3. **状态变体从剧情反推。**皮箱有合上/打开，状纸有藏着/摊开——道具的状态弧跟着剧情走，每个状态一条英文提示词，会各生成一张参考。没有状态变化的道具写一个主状态即可。

4. **尺度必须写死。**`scale` 三档（手持级/桌面级/家具级），`image.prompt` 和 `image.sheet` 里**必须出现对应英文短语**（handheld scale / tabletop scale / furniture scale）——AI 把手持道具画成家具尺寸是高频事故，validate 会对着查。

5. **白底、无人、无手。**道具参考图要被贴进各种镜头，必须纯白背景可抠；**拿着道具的手是最常见的污染**，反向提示词必须禁 hands/fingers。validate 三样都查。

6. **关联要挂上。**`relatedScenes` 挂它主要出现的场景（id 必须存在），`carriedBy` 写谁带着它（自由文本）。这两样进报告，是排生成任务时查「这场戏桌上该有什么」的索引。

7. **提示词永远英文，绝不出现角色名**——图像模型会把它认识的名字画进去。风格整段取用当前预设的渲染句（与场景同一套）。

## 输入格式

```
Style: realistic
候选道具线索（从原文/大纲摘出）：
- 沈知微始终抱着一只旧皮箱，指节发白（第 1–6 集，开箱是收束爆点）
- 陆行远口袋里的硬东西，第 3 集掏出是一方旧砚，砚底刻着县衙的印
- 胡二爷的两箱货（挑着走，无特写）
已有场景：S01 渡船船舱、S02 渡口栈桥、S03 对岸芦苇滩
```

上面第三条就该落选——有出场无特写，不承载剧情转折。
