# 切镜：一集怎么分段、怎么切

一次任务切一集。你拿到 seedScenes 工作底稿（每场的节拍清单：编号、动作/台词、每拍秒数、说话人）、场景卡、角色卡。产出：把这一集的 `segments` 从空切满，然后删掉 `seedScenes`。

## 先明确观看逻辑，再打包生成段

1. 先继承导演镜头目的、顺序、覆盖与接点；没有导演包时先完成这些判断，再将镜头分配到生成段。不得让 API 长度决定每场必须切几镜。
2. **段 = 一次生成调用**，默认上限 15 秒且不跨场次。普通切 2–5 秒和短信息插入 1.2 秒是当前参数基线；长镜头与特殊节奏按已支持参数和导演依据调整。打包时核对动作、空间、对白和跨段衔接。
3. **每切写一条分镜图提示词，是否出图、是否投喂由生成模式决定**：I2VA/FL2VA/L2VA 才把真实首尾帧当时间锚；Ref2VA 的分镜图是候选参考，审核后按人物身份、场景拓扑、关键道具、姿态或信息内容等互补职责择优挂载，不把每一格机械钉到切点。

## 硬规则

1. **认领是地基。** 每个分镜声明 `beats:[起,止]`，全场连续区间、不重不漏。切完在心里过一遍：每场第 1 拍到最后一拍都有主吗？
2. **秒数是下单不是估算。** 分镜秒数直接决定切点时刻和对齐指令——改秒数必须同步改 `h3Prompt`，validate 逐字对账，改一边必被拦。
3. **台词装得下。** 认领节拍的台词秒数 ≤ 分镜秒数。4.4 秒的台词就给 5 秒的切。
4. **景别短语进分镜图提示词，运镜词进自己的 [Shot k] 段落。** 运镜直接用 H3 官方词表（Push In / Pan Left / Tracking Shot…），写成自然英文动作（a slow push in toward…）。
5. **提示词禁角色名。** 分镜图和 H3 描述都用通用身份（an old ferryman、a young woman in a plain qipao），人名只许出现在 `<d>` 台词里。
6. **主要认领与补充覆盖分开。** `beats:[起,止]` 负责唯一认领；额外的证据插入、主观内容或反应镜头使用 `coverageOf:[起,止]`，它不再次消费节拍，但必须指向同场已被主要认领的节拍。

## 屏幕、文件和信息载体

先问观众必须看清什么，再选择镜头：

- `contextual`：只需知道人物在看/使用，内容本身不推动剧情。
- `insert`：手机、文件或道具至少占画面 50%，用于少量关键图像或状态。
- `full-frame-content`：把人物看到的视频/照片作为主观内容切满画面，占比至少 90%，再切回人物反应。
- `post-composite`：聊天、金额、车次、余额等需要精确文字的界面，使用干净可跟踪屏幕，后期合成。

典型覆盖是“人物与空间 → 载体插入 → 全屏内容/精确信息 → 人物反应”。环境镜头不能同时承担人物关系和小屏幕细节阅读。已有清楚反应时，不再堆一个只放大裁切的重复眼睛镜头。

## 导演运镜手感（不设门，但决定像不像专业分镜）

- **3 秒是常用呼吸，不是统一模板。** 建立、动作、信息和反应按阅读负担分配；简单图像插入可以 1.2–2 秒，克制反应可以 2.5–4 秒。节奏带应深浅相间、长短相间。
- **提速做非等比例压缩。** 先砍观众已经读懂后的尾巴和重复建立，再压次要信息，保护剧情必读内容与转折反应。不要把整个片段直接 1.25 倍速后当正式方案。
- **画面内运动单独写。** 每镜先写主体/道具/环境的主运动及 `setup → trigger → development → settle`，再写摄影机运动；固定机位仍必须有可见动作或状态变化。
- **对白按权力和反应切。** 正反打、双人镜头、听者反应或不切均可；不为每句对白机械换脸。能否同段生成由参考数量、表演和接点决定。
- **开场先确定观众要知道什么。** 主体行动、静态证据、声音或空间反常都可建立钩子；不强迫奔跑或套用三镜组合，按导演方案保证信息清晰。
- **关键动作独立成切。**「她一把按住箱盖」这种拍值得单独一格 2 秒的特写插入（insert）——它是节奏的重音。
- **反应镜头要带来信息。** 只有改变关系、认知或节奏时才补反应；仍计入生成、筛选与剪辑成本。VO 覆盖画面也需声画关系和时长验证。
- **动接动。** 上一切结尾的动势（手伸向箱子）接下一切开头的动势（手被按住），段内连贯性交给 H3，切点选在动作中间而不是动作完成后。
- **段的最后一切留钩。** 每段结尾的分镜要么是悬念的具象（口袋、铜扣、灯），要么是下一段的引子——段与段之间也是剪辑点。
- **运镜克制。** 固定镜头是默认；推给情绪、拉给收场、跟给移动。一段里超过两种运镜就该问自己是不是在炫技。

## 参考图纪律（分镜图质量的一半在这）

最终 H3 提示词后置：先由 `frame` 生成候选素材并完成 QC，再按通过素材的真实 Picture 顺序调用官方 `h3-prompt-writing`。不要先写完整 Ref2VA 提示词，再寻找勉强匹配的图片。

分镜图生成 = 提示词 + 参考图。切镜时就想好每格要挂哪些参考：

- 场景设定图（该段场景 + 光照状态）——必挂
- 画内每个角色的设定图——有几个挂几个
- 画内叙事道具的设定图——有就挂

提示词与参考图冲突时，模型听参考图的——所以提示词专心写构图、**此刻的位置状态**（已上船 / 在舱内 / 在桥头）和姿态，长相材质交给参考图。画面里出现的大资产（船、车、宅门）也要挂它自己的设定图，不挂就每帧长得不一样。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 无效停留 | 镜头既无新信息也无表演价值 | 删除冗余或改变调度，不因单镜头长就机械加切 |
| 均匀病 | 每切都是 3 秒中景 | 深浅相间、长短相间才是节奏 |
| 秒数漂移 | 改了分镜秒数忘改提示词 | validate 会拦：对齐指令和切点时刻逐字对账 |
| 台词爆仓 | 4.4 秒的台词塞 3 秒的切 | 加秒或拆切 |
| 声景漏改 | 画面改成搭手卸担，环境音还写着铜铃撞击 | **声景也是动作指令**——剧本动作一改，描述、声景、中文对照三处一起改（踩过：视频真把撞击演出来了） |
| 特写失忆 | 大特写的道具和设定图长得不一样 | 挂道具设定图当参考，提示词提锚点特征 |
| 换景不换段 | 一段里从栈桥切进船舱 | 换景必开新段——一段一个环境锚 |
| 改切不读邻切 | 第 1 切改成岸路奔跑，第 2 切还写着栈桥才露出来，图却画在栈桥上 | 改一切连读前后切，分镜图和文字逐格对照——位置是连续状态 |
